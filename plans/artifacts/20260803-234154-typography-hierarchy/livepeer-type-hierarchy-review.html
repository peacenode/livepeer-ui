Existing families

The current apps use several valid hierarchy families. The system needs names and boundaries rather than one identical scale everywhere.

Surface Current hierarchy What it establishes
Console 32 light → 24 medium → 14–18 medium → 14 body → 12 metadata Airy page framing with compact operational content
Tool workspace 20 workspace → 24 entity → 14–16 item → 12 metadata Dense persistent workspace hierarchy
Protocol education 30 page → 18 section → 14–16 step → 14–16 support Readable explanation and sequence
Public brand 36 mobile hero → 48–64 desktop → 36–60 section → 14–16 body Expressive display hierarchy; currently the most variable
Editorial 30–48 title → 14 metadata → constrained prose Long-form reading and article identity
Docs 30 semibold page → 20 semibold section → 14 body → 12 metadata Compact reference documentation
Data summary 24–60 metric → 12–14 label Numerical prominence with Inter tabular figures
